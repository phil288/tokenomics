Tokenomics: see how many tokens — and dollars — your AI coding tools save you

A free, open-source, self-hosted dashboard for Claude Code quota, Cursor and Antigravity usage, and the token savings of RTK, Headroom and Caveman. Live, on one screen, with real cost math.

View on GitHub Install in one line

Features

Claude Code quota tracker

5-hour session and weekly limits from Claude Code's own /usage, with a pacing tick showing how much you can still spend today.

Cursor & Antigravity usage

Cursor billing-period usage and Google Antigravity quota on the same board as Claude.

Token savings, in dollars

RTK, Headroom and Caveman savings merged, with per-model raw → real → saved USD including prompt-cache pricing.

Live over SSE

Numbers update as you work. Time-series history for tokens saved, cost and quota burn.

Pacing alerts

Optional desktop notifications when a quota burns through its daily or hourly budget.

Private & dependency-free

Runs on localhost with Node.js built-ins only. Your usage data stays on your machine.

Install

Linux (systemd user service, serves on http://localhost:3000):

curl -fsSL https://raw.githubusercontent.com/phil288/tokenomics/main/install.sh | sh

Or run it anywhere Node.js 18+ runs:

git clone https://github.com/phil288/tokenomics.git
cd tokenomics
node server.js

macOS machine-wide (launchd) install and all configuration options are in the README.

FAQ

How do I see my Claude Code usage and quota?
Tokenomics polls Claude Code's own /usage command and shows your 5-hour session and weekly limits as live bars, with a pacing tick that tells you how much you can still use today.
Does Tokenomics send my data anywhere?
No. It runs on localhost and reads local files and CLI output. The only outbound calls are the optional Cursor usage API, and update checks against GitHub and PyPI.
Which AI tools and models are supported?
Claude Code, Cursor and Google Antigravity for usage and quota; RTK (Rust Token Killer), Headroom and Caveman for token savings. Cost math covers Anthropic Claude, Google Gemini and Cursor models. OpenAI / Codex is not supported yet — contributions welcome.
Is Tokenomics free?
Yes. It is open source under the Apache-2.0 license and has zero runtime dependencies beyond Node.js 18 or newer.
